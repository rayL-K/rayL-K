## English

I'm a student developer in Nanjing, China. I started VeyraLux to make software that listens, remembers, and speaks up, and I like building the whole stack myself: languages, compilers, backends, and the web pages people see first.

### What I'm building

- **[Zamak](https://github.com/VeyraLux/Zamak)**: a statically typed language with Python-style syntax. It compiles to small native executables on Windows, Linux, and macOS, catches ownership and type mistakes before the program runs, and has its own package index.
- **[Anima](https://vcr.veyralux.org)**: a virtual companion you meet in the browser. It listens, remembers your conversations, and joins in. Source: [VeyraLux/Viusual_Companion_Robot](https://github.com/VeyraLux/Viusual_Companion_Robot).

### Other projects

- **[ToDOCX](https://github.com/rayL-K/ToDOCX)**: turns Markdown, DOCX, and LaTeX into formatted DOCX files.
- **[Jumper](https://github.com/rayL-K/Jumper)**: plays the WeChat "Jump Jump" game with YOLO object detection.
- **[Charles-5.2.2-zh-CN](https://github.com/rayL-K/Charles-5.2.2-zh-CN)**: a Simplified Chinese localization of Charles Proxy.

### Tools I use

Rust · C · Python · TypeScript · Vue · Qt/C++ · Cloudflare Workers · embedded Linux
