<div align="center">

**[Zamak](https://github.com/VeyraLux/Zamak)**：语法像 Python、运行像 C 的静态类型编程语言。没有垃圾回收也内存安全，编译成小巧的原生程序，自带格式化、测试、包管理和 VS Code 语言服务器，也为 AI 编程助手设计。
A statically typed language that reads like Python and runs like C. Memory-safe without a garbage collector, compiled to small native executables, with a formatter, test runner, package manager, VS Code language server, and a design built for AI coding agents.
